## LOADER STABILITY BUG FOUND & FIXED (blocking)
SIGHUP → poll() returns EINTR → errno clobbered by reconcile's fopen()
before the check → false "poll failed errno=22" exit → BPF object closed
→ ALL MAPS GONE → silent unprotected state.
Fix: capture errno immediately after poll (perr), check before any
libc call. Verified: 5×HUP back-to-back, loader alive, zero spurious
exits. Lesson recorded: errno is a hot potato — snapshot it first.
