## BUGS FOUND & FIXED DURING RUN11
1. REGF recorded ISSUER uid (root=0) as owner -> client uid1000 always
   denied. Fix: owner packed into REGF args[2] = (uid<<32)|dev.
2. INVALID TEST ×2 ("$() subshell" class): fd number printed by pm-tx
   request dies with that process; presenting the NUMBER from another
   pid resolves nothing. This is FD semantics WORKING AS DESIGNED —
   named anti-pattern: subshell splits execution identity.

## SEMANTIC TABLE (FD mode supersedes nonce mode)
possession of fd            = necessary
+ uid == cap.owner_uid      = required (anti SCM_RIGHTS handoff)
+ first-binder-wins tgid    = fork/handoff deny after bind
+ now < expires             = TTL bound
+ exec                      = authority preserved (fd not CLOEXEC)
+ close/exit                = authority gone
+ struct-file reuse         = rejected via f_inode guard
